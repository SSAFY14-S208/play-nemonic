Artifact Pipeline

사용자가 만든 콘텐츠는 하나의 artifact로 저장되고, 이후 갤러리 조회, 링크 공유, 커뮤니티 보드 게시까지 이어집니다.

Drawing Fortune Flipbook Relay
01

콘텐츠 생성

무한캔버스, 운세, 플립북, 릴레이에서 사용자가 결과물을 만듭니다.

02

Artifact 저장

결과물 파일과 메타데이터를 묶어 재조회 가능한 단위로 관리합니다.

03

개인 갤러리

사용자는 완성된 결과물을 갤러리에서 다시 확인하고 공유할 수 있습니다.

04

커뮤니티 확산

선택한 결과물을 커뮤니티 보드에 메모처럼 붙여 다른 사용자와 함께 봅니다.

공유 링크 / 이미지 조회

artifact는 외부 공유 링크와 이미지 조회 흐름으로 이어져 서비스 밖에서도 결과물을 보여줄 수 있습니다.

커뮤니티 보드 출력

같은 artifact를 게시용 이미지 스냅샷으로 변환해 커뮤니티 보드에 네모닉 메모처럼 남깁니다.
