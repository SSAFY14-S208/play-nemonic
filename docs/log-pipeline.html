Nemonic Log Pipeline

EC2 단일 호스트의 Docker 컨테이너 로그를 수집, 버퍼링, 파싱, 저장, 시각화하는 관측성 전용 구조입니다. 전체 시스템 아키텍처와 분리해 로그 데이터가 어디서 생기고 어디에서 분석되는지에 집중했습니다.
로그 이벤트 흐름 메트릭 수집 흐름
stdout 자동 수집 Kafka backpressure 5개 인덱스 라우팅 Backoffice 분석
1

Docker Containers

Nginx, Frontend, Spring Boot, FastAPI 등 모든 컨테이너가 stdout/stderr로 로그를 남깁니다.
client-web 페이지뷰, 퍼널, 프론트 오류
api-server API, WebSocket, 도메인 이벤트
backoffice-api 운영자 액션, 감사 로그
nginx access log, 라우팅, status
2

Fluent Bit

Docker JSON 로그 파일을 tail하고 컨테이너 메타데이터를 붙여 Kafka로 전송합니다.
Tail input/var/lib/docker/containers/*/*-json.log
Lua enrichcontainer_id, container_name, host 주입
Offset DBSQLite로 재시작 후 중복/유실 방지
BufferKafka 장애 시 50MB 메모리 버퍼
3

Kafka

Logstash와 OpenSearch가 느려져도 앞단 로그 수집이 바로 막히지 않도록 완충합니다.
Topicnemonic-logs 단일 토픽
Retention7일 보관으로 재처리 윈도우 확보
KRaftZookeeper 없이 단일 브로커 운영
Replay파싱 룰 변경 시 재소비 가능
4

Logstash

자기 로그를 제거하고 JSON/grok 파싱 후 이벤트 성격에 맞는 인덱스로 분기합니다.
Self-log dropLogstash/Fluent Bit 무한 루프 차단
NormalizeDocker log 필드 정규화
Routeaudit, error, biz, access, system 분류
Fallback미분류 로그는 system-logs로 보존
5

OpenSearch

분류된 로그를 검색 가능한 일자/월 단위 인덱스에 저장하고 분석 화면으로 제공합니다.
biz서비스 행동 · 90일
error예외 · 90일
system시스템 로그 · 30일
accessHTTP 접근 · 14일
audit운영 감사 · 영구
VisualizationBackoffice Analytics, OpenSearch Dashboards
SnapshotMinIO S3 호환 저장소로 일일 백업
Metrics Side Lane 로그와 별도로 숫자 지표는 Prometheus 계열로 수집합니다.

Scrape Targets

Spring Boot actuator, Nginx exporter, node-exporter, cAdvisor, FastAPI exporter를 주기적으로 수집합니다.

Prometheus

RPS, latency, error ratio, WebSocket sessions, CPU, memory, disk 같은 시계열 값을 저장합니다.

Grafana / Backoffice

엔지니어는 Grafana에서 시스템 헬스를 보고, 운영자는 백오피스 분석 화면에서 로그와 메트릭을 함께 확인합니다.

Backpressure

Kafka를 중간에 두어 Logstash나 OpenSearch가 지연되어도 Fluent Bit가 즉시 막히지 않도록 했습니다.

Retention by Value

감사 로그는 영구 보존하고, access/system 로그는 짧게 유지해 단일 EC2 디스크 사용량을 제어합니다.

Secure Analysis

운영 화면은 백엔드 프록시를 거쳐 OpenSearch와 Prometheus를 조회하므로 내부 URL과 자격증명을 프론트에 노출하지 않습니다.
