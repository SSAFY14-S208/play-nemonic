# 9. 휴대폰 그리기

휴대폰 그리기는 갤러리 내부 콘텐츠이다. 갤러리는 UI상 휴대폰 형태로 제공되며, 다른 부스 결과물을 모아두는
역할 외에도 휴대폰 안에서 직접 그림을 그려 별도 산출물로 보관할 수 있다.

## 기획 의도

- 사용자가 자신의 휴대폰을 꾸미듯 가볍게 창작하는 경험을 제공한다.
- 다른 부스를 거치지 않아도 즉시 산출물을 만들 수 있게 한다.
- 완성한 그림은 커뮤니티 캔버스에 메모지로 인쇄해 자랑할 수 있다.

## 핵심 재미 요소

- 갤러리, 즉 휴대폰이라는 개인 공간 안에서 자유롭게 그리는 경험
- 낮은 진입 장벽으로 즉시 산출물을 만드는 경험
- 그린 그림을 메모지로 인쇄해 커뮤니티 벽에 게시하는 출력 경험

## 사용자 흐름

1. 커뮤니티 캔버스 또는 메뉴에서 갤러리, 즉 휴대폰 UI를 연다.
2. 갤러리 내부의 그리기 버튼을 눌러 빈 캔버스를 연다.
3. 컬러 드로잉 도구로 자유롭게 그린다.
4. 저장 시 `phone_artifact`로 적재되어 갤러리 목록에 즉시 표시된다.
5. 선택적으로 갤러리에서 결과물을 꺼내 메모지로 출력하고 커뮤니티 캔버스에 부착한다.

## 드로잉 도구

우당탕 릴레이 드로잉과 플립북의 컬러 드로잉 도구를 동일하게 사용한다.

- 펜/브러시, 굵기 3단계
- 기본 12색 팔레트와 커스텀 색상
- 지우개
- Undo/Redo
- 페인트 채우기
- 획 지우개
- 전체 지우기

멀티플레이 콘텐츠가 아니므로 제한 시간과 자동 제출 정책은 적용하지 않는다.

## 결과물 저장 구조

- 완성한 그림은 PNG로 변환해 MinIO에 영구 저장한다.
- 메타데이터는 PostgreSQL에 저장한다.
- `phone_artifact` 테이블은 생성자 UUID, 생성 시각, 이미지 URL 등을 저장한다.
- `artifact.kind = phone`으로 분류되어 갤러리 목록 쿼리에서 다른 부스 결과물과 함께 통합 노출된다.
- 저장 즉시 생성자의 갤러리 목록에 표시된다.

## 소유권 및 생명주기

- 결과물은 생성자 UUID에 귀속된다.
- UUID가 유효한 동안에만 본인 갤러리에서 조회하고 삭제할 수 있다.
- UUID를 잃으면 갤러리에서 조회할 수 없지만 DB/MinIO 원본은 삭제되지 않는다.
- DB에서 별도 만료 정책은 적용하지 않는다.
- 커뮤니티 캔버스에 게시된 메모 복사본에만 FIFO 정책이 적용된다.

## 커뮤니티 캔버스 인쇄

- 갤러리에서 `phone_artifact`를 꺼내 메모지로 출력하고 커뮤니티 캔버스에 게시할 수 있다.
- 같은 `phone_artifact`를 여러 번 게시할 수 있다.
- 게시된 각 메모 복사본은 독립적으로 FIFO, 신고, 숨김, 삭제 정책을 적용받는다.
- 커뮤니티 게시 복사본이 FIFO로 제거되어도 DB/MinIO 원본 `phone_artifact`는 제거되지 않는다.
- 커뮤니티 캔버스에 게시된 휴대폰 그리기 메모에는 신고 5회 누적 자동 숨김과 AI 모더레이션 정책을 동일하게 적용한다.
