# 4. 플립북

## 기획 의도

갈틱폰에서 착안한 릴레이 드로잉 기반 협동 플립북 콘텐츠이다. 참여자들이 앞사람 그림을 가이드로 받아
다음 프레임을 이어 그리고, 완성 프레임들을 연속 재생하면 짧은 애니메이션이 된다.

각 프레임은 메모지로 개별 인쇄되어 실제 플립북처럼 넘기며 볼 수 있고 GIF로도 다운로드할 수 있다.
N명이 참여하면 N개의 플립북이 탄생한다.

## 핵심 재미 요소

- 앞사람 그림을 보고 이어 그리는 릴레이의 예측 불가능함
- 마지막에 프레임이 한꺼번에 움직이는 보상감
- 인쇄된 메모지를 실제로 넘기며 애니메이션을 확인하는 경험
- 공유하기 좋은 GIF 결과물

## 방 생성 및 참여

- 방 생성 및 참여 정책은 릴레이 드로잉과 동일하다.
- 최소/최대 인원은 백오피스 시스템 파라미터 `flipbook.room_participant_limit`을 따른다.
  백엔드 기본값은 최소 2명, 최대 6명이다.
- 게임 시작 시 참여자 수만큼 플립북을 생성한다.
- 플립북당 목표 프레임 수는 백오피스 시스템 파라미터 `flipbook.min_frames_per_flipbook`을 따른다.
  백엔드 기본값은 8프레임이다.
- 현재 백엔드는 라운드 수를 플립북당 목표 프레임 수와 동일하게 잡는다.
  예: 목표 프레임 수가 8이면 참여자 수와 무관하게 8라운드를 진행한다.
- 방장은 게임 시작, 제한 시간 설정, 방 종료를 결정한다.
- 방장은 가장 먼저 입장한 참여자이며 이탈 시 입장 순서 기준 다음 참여자에게 자동 승계된다.

## 제한 시간 및 라운드 수

- 제한 시간 선택지는 백오피스 시스템 파라미터 `flipbook.room_time_limit_seconds`를 따른다.
  백엔드 기본값은 45초이고 기본 허용값은 30초, 45초, 60초이다.
- 각 프레임 드로잉에 동일한 제한 시간이 적용된다.
- 기본 라운드 수는 `flipbook.min_frames_per_flipbook` 값이다.
- 최종 플립북은 N개 생성되고, 각 플립북은 정상 제출 기준으로 목표 프레임 수만큼 구성된다.
- 전체 제출 배정 수는 `N * 라운드 수`이다.
- 실시간 타이머를 표시한다.
- 제한 시간이 끝나면 백엔드는 `ROUND_TIME_UP` 이벤트를 발행하고, 자동 제출 유예 시간이 지난 뒤
  미제출 프레임을 빈 프레임으로 자동 제출 처리한다.
- 자동 제출된 빈 프레임은 최종 GIF 결과물에 포함하지 않는다.

## 드로잉 도구

릴레이 드로잉과 동일한 도구를 사용한다.

- 펜/브러시, 굵기 3단계
- 기본 12색과 커스텀 색상
- 지우개와 크기 조절
- Undo 최대 20단계
- Redo
- Flood Fill
- 획 지우개
- 전체 지우기
- 컬러 그대로 출력

## 릴레이 진행 방식

- 라운드 1에서 모든 참여자가 동시에 각자의 캔버스에 첫 프레임을 그린다.
- 라운드 2 이후 캔버스가 입장 순서 기준 다음 참여자에게 순차 패싱된다.
- 순서는 1번, 2번, 3번, ..., N번, 1번 순환이다.
- 이전 프레임은 오니언 스킨 반투명 가이드로 표시된다.
- 오니언 스킨은 화면에서만 제공되며 인쇄되지 않는다.
- 자신이 이전에 그린 캔버스가 연속으로 돌아오지 않는다.

## 이탈, 방장 이탈, 입장 제어

- 중도 이탈, 방장 승계, 게임 중 신규 입장 차단은 릴레이 드로잉과 동일한 정책을 적용한다.
- 기존 참여자만 설정된 재접속 유예 시간 내 재접속을 허용한다.
- 신규 UUID는 게임 진행 중 입장 차단한다.

### 이탈자의 프레임 처리

플립북은 릴레이 드로잉과 다르게 프레임 단위로 폐기 판단한다.

- 그리기 전 이탈한 빈 프레임은 해당 프레임만 폐기한다.
- 플립북 자체는 살아남고 N-1프레임 애니메이션으로 완성될 수 있다.
- 이탈 전 정상 제출된 프레임만 결과에 사용한다.
- 빈 프레임은 결과물에 포함하지 않는다.
- 남은 프레임은 compact되어 순서대로 재생된다.
- 프레임 개수만 줄어들 뿐 결과물은 유지된다.
- 이탈자의 현재 라운드 미제출 프레임은 재접속 유예 만료 시 빈 프레임으로 자동 제출된다.
- 이탈자의 이후 라운드 배정은 해당 라운드가 현재 라운드가 되었을 때 제한 시간 정책에 따라
  빈 프레임으로 자동 제출될 수 있다.
- 오니언 스킨은 서버가 제공하는 이전 제출 프레임이 있을 때만 표시한다.
- 이탈로 남은 인원이 2명 이하가 되어도 게임은 중단하지 않고 끝까지 진행한다.
- 모든 프레임이 빈 프레임 또는 자동 제출 프레임이라 최종 결과에 사용할 프레임이 0개이면,
  GIF와 갤러리 결과물을 만들지 않고 방을 `CLOSED`로 전환한다.

## 네트워크 끊김 대응

- 릴레이 드로잉과 동일하게 `roomId + UUID`로 재접속한다.
- 방 URL에는 `roomId`가 포함된다.
- UUID는 `localStorage + cookie`에서 복구한다.
- 네트워크 순단, 새로고침, 탭 닫기 후 재진입은 설정된 재접속 유예 시간 내 조건부 복귀 가능하다.
- 재접속 유예 시간은 백오피스 시스템 파라미터 `flipbook.reconnect_grace_seconds`를 따른다.
  백엔드 기본값은 10초이다.
- 캐시 삭제로 UUID가 사라지면 복귀 불가하다.
- 끊김 감지 시 “연결 끊김 — 재연결 중...” 오버레이와 캔버스 잠금을 적용한다.
- 현재 프레임 데이터는 `roomId + frameId` 키로 localStorage에 임시 저장한다.
- 재연결 실패 시 백엔드는 해당 참여자를 dropped 처리하고 미제출 현재 프레임을 빈 프레임으로 자동 제출한다.
- 동일 UUID 중복 접속은 기존 세션 kick 후 신규 연결을 세션 복귀로 처리한다.

## 사용자 흐름

1. 방 생성 또는 공유 링크/QR로 입장한다.
2. 대기 화면에서 참여자를 확인한다.
3. 방장이 제한 시간을 설정한다.
4. 설정된 최소 인원이 모이면 시작한다.
5. 라운드 1에서 첫 프레임을 그린다.
6. 이후 캔버스가 순차 패싱되고 이전 프레임을 오니언 스킨으로 보며 이어 그린다.
7. `flipbook.min_frames_per_flipbook`으로 정한 목표 프레임 수만큼 반복한다.
8. 완성 프레임들이 메모지로 개별 인쇄된다.
9. 프레임을 넘기며 플립북 애니메이션을 재생하는 연출을 보여준다.
10. GIF 다운로드 또는 외부 공유를 제공한다.

## 주요 기능

- 방코드, 링크, QR 초대
- 릴레이 프레임 드로잉
- 오니언 스킨 가이드
- 제한 시간 타이머
- 자동 애니메이션 합성
- GIF 다운로드
- 외부 공유

## 결과 응답 구조 및 재생

서버는 방코드 기준으로 생성된 플립북 결과 목록과 각 결과를 구성하는 프레임 목록을 함께 반환한다.

```json
{
  "roomCode": "AB3K9Q",
  "roomStatus": "FINISHED",
  "ready": true,
  "resultCount": 1,
  "results": [
    {
      "flipbookIndex": 0,
      "galleryId": "gallery_uuid",
      "artifactId": "artifact_uuid",
      "thumbnailUrl": "https://minio/.../thumbnail.png",
      "gifUrl": "https://minio/.../result.gif",
      "firstImageUrl": "https://minio/.../frame_0.png",
      "createdAt": "2026-05-08T14:00:00",
      "frames": [
        {
          "frameIndex": 0,
          "imageUrl": "https://minio/.../frame_0.png",
          "drawnByUserUuid": "user_uuid_a",
          "drawnByNickname": "닉네임A"
        },
        {
          "frameIndex": 1,
          "imageUrl": "https://minio/.../frame_1.png",
          "drawnByUserUuid": "user_uuid_b",
          "drawnByNickname": "닉네임B"
        }
      ]
    }
  ]
}
```

- `results`는 `flipbookIndex`별 최종 결과 목록이다.
- `frames`는 이미지 URL, 그린 참여자 UUID, 그린 참여자 닉네임을 포함한다.
- 프레임은 인덱스 순으로 정렬된다.
- `gifUrl`은 서버에서 합성된 GIF 파일의 MinIO 다운로드 URL이다.
- 프론트는 `frames`로 한 장씩 넘기는 프레임 뷰어를 제공한다.
- 프레임 하단에 `drawnByNickname`을 표시한다.
- 프론트는 `gifUrl`로 자동 재생 GIF를 표시한다.
- GIF 다운로드와 SNS 공유 버튼을 제공한다.
- 최종 결과에 사용할 프레임이 0개인 경우 결과 응답은 준비되지 않으며, 방은 `CLOSED` 상태가 된다.

## 결과물 소유권 및 생명주기

- 완성 결과물은 게임 종료 시점까지 남은 참여자의 UUID에 귀속된다.
- 잔류 참여자 UUID 목록을 DB에 저장한다.
- 중도 이탈자는 갤러리 지급 대상에서 제외된다.
- 결과물은 잔류 참여자 갤러리에 자동 보관된다.
- 제출된 원본 프레임 이미지와 생성된 GIF는 MinIO에 영구 저장된다.
- 최종 결과에 사용할 프레임이 0개이면 GIF, 썸네일, artifact, gallery row를 생성하지 않는다.
- 별도 삭제 정책을 적용하지 않는다.
- UUID가 유효한 동안 갤러리에서 꺼낼 수 있다.
- UUID를 잃으면 갤러리 조회는 불가하지만 MinIO 원본은 삭제되지 않는다.
- 커뮤니티 벽 게시가 가능하다.
- GIF 애니메이션 결과물도 커뮤니티 벽에 게시할 수 있다.
- 같은 결과물을 여러 번 게시할 수 있다.
- 게시 복사본은 FIFO, 신고, 삭제 정책을 독립 적용받는다.
- 커뮤니티 게시 복사본이 삭제되어도 MinIO 원본은 제거되지 않는다.

## 연출 포인트

- 프레임 전달 모션
- 프레임 한 장씩 인쇄되는 모션
- 인쇄된 메모지가 빠르게 넘어가며 애니메이션이 되는 플립북 연출
- 종이 넘기는 소리, 인쇄 소리, 완성 효과음
- 대기 화면에서 필름 프레임이 하나씩 채워지는 모션
