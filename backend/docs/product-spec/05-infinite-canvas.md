# 5. 무한 캔버스

## 기획 의도

피그잼에서 착안한 실시간 협업 화이트보드 콘텐츠이다. 무한히 확장되는 캔버스 위에서 여러 명이 동시에
드로잉하고, 스티키노트, 도형, 텍스트, 이미지 등 다양한 도구로 함께 창작한다.

완성된 결과물의 원하는 영역을 선택해 네모닉으로 포스트잇 출력이 가능하다. 대기방 없이 링크만 공유하면
바로 캔버스에 합류하는 자유로운 구조이다.

## 핵심 재미 요소

- 친구와 같은 캔버스에서 실시간으로 함께 그리는 경험
- 다양한 도구로 자유롭게 표현
- 그린 결과물을 바로 포스트잇으로 출력하는 물리적 보상
- AI 기능으로 창작 폭을 넓히는 경험
- 캔버스에 사람이 있는 동안 살아 있고 자유롭게 들어오고 나갈 수 있음

## 참여 방식

- 대기방 없이 링크를 공유하면 바로 캔버스에 합류한다.
- 릴레이 드로잉/플립북의 10초 재접속 유예는 무한 캔버스에 적용하지 않는다.
- 마지막 1명이 명시적 탈퇴, 새로고침, 탭 닫기, 네트워크 순단 등 어떤 이유로든 연결을 잃으면 캔버스가 즉시 종료된다.
- Redis 내 작업물과 활성 캔버스 메타데이터는 즉시 evict한다.
- DB에는 무한 캔버스 메타데이터를 영구 보존하지 않는다.

| 항목 | 정책 |
| --- | --- |
| 캔버스 생성 | 새 캔버스 만들기 선택 시 고유 캔버스 URL 생성 |
| 초대 | 공유 링크 또는 QR 코드 |
| 이름 | 릴레이/플립북과 동일하게 기존 익명 사용자 닉네임을 사용, 닉네임이 없으면 생성/입장 전에 입력 |
| 인원 제한 | 1명 이상, 동시 접속 최대 6명, 안정성 검증 후 10명 확장 가능 |
| 합류 | 공유 링크/QR의 초대코드를 `invite` API로 처리, 활성 캔버스이면 언제든 합류 가능 |
| 퇴장 | 자유 퇴장, 마지막 참여자 이탈 시 캔버스 종료 |
| 정원 초과 | 입장 차단, 대기열/뷰어 모드 없음 |

## 데이터 저장 구조

무한 캔버스는 활성 캔버스 상태를 Redis에만 저장한다. 캔버스 자체 메타데이터는 영구 보존하지 않으며,
사용자가 출력한 포스트잇 결과물만 DB와 MinIO에 영구 보존한다.

| 구분 | 저장소 | 저장 데이터 | 생명주기 |
| --- | --- | --- | --- |
| 활성 캔버스 상태 | Redis | 요소, 드로잉, 커서 위치, 요소 잠금, 참여자 세션, 활성 캔버스 메타데이터 | 마지막 참여자 이탈 즉시 evict |
| 출력 포스트잇 | DB + MinIO | 포스트잇 이미지와 메타데이터 | 영구 보존 |

- 캔버스가 살아 있는 동안 작업물과 세션 상태는 Redis에만 존재한다.
- DB에는 무한 캔버스 레코드나 메타데이터를 저장하지 않는다.
- WebSocket 메시지로 변경 사항을 실시간 동기화한다.
- 종료 시 Redis 키는 즉시 evict되어 사용자 관점에서 복구 불가하다.
- 출력 포스트잇은 출력 시점에 DB + MinIO에 저장되므로 캔버스 종료와 무관하게 보존된다.
- 운영자는 캔버스 내부 작업물 Redis 데이터를 열람할 수 없다.
- 운영자는 Redis에 남아 있는 활성 캔버스 메타데이터만으로 좀비 캔버스 식별과 강제 종료를 수행한다.

## 캔버스 도구

- 펜/브러시: 색상, 굵기, 투명도 조절
- 스티키노트: 색상별 노트 배치, 텍스트 입력, 크기 조절, 이동
- 투명 라벨/스티커: 캐릭터, 이모지, 장식 세트 또는 AI 이모지 결과 활용
- 도형: 사각형, 원, 삼각형, 화살표, 선 등
- 텍스트: 폰트 크기와 색상 조절
- 이미지 업로드: 이미지 배치, 크기 조절, 이동
- 갤러리: 각 부스 결과물을 이미지 요소로 캔버스에 배치
- 선택/이동: 요소 선택, 이동, 크기 조절, 삭제
- 핀치 줌과 스크롤로 무한 캔버스를 탐색한다.
- 각 사용자의 커서와 닉네임이 실시간 표시된다.
- 누구나 모든 요소를 수정, 이동, 삭제할 수 있다.

## 포스트잇 출력

- 캔버스 원하는 영역을 컬러 그대로 포스트잇 출력한다.
- 출력 전 비율 프리셋을 선택한다.
- 예: 정사각형 1:1, 세로 메모 2:3, 가로 메모 3:2, 파노라마 4:1
- 선택한 비율에 맞춰 고정 비율 프레임을 표시한다.
- 사용자는 선택 박스를 드래그로 이동하고 모서리 핸들로 크기 조절한다.
- 크기 변경 시 선택 영역 비율은 유지된다.
- 출력물이 잘리거나 늘어나지 않게 한다.
- 출력된 포스트잇은 커뮤니티 벽에 부착하거나 개인 소장할 수 있다.
- 같은 포스트잇을 커뮤니티 벽에 여러 번 게시할 수 있다.
- 게시 복사본은 독립적으로 FIFO, 신고, 삭제 정책을 적용받는다.
- 출력 횟수 제한은 두지 않는다.

## AI 기능

AI 기능은 기본 드로잉/협업 기능과 독립적으로 동작한다. AI 없이도 핵심 체험은 완전해야 한다.

### AI 이모지 생성

- 사용자가 텍스트 프롬프트를 입력한다.
- 스타일 프리셋을 선택할 수 있다.
- 예: 카툰, 픽셀, 3D 클레이, 수채화, 플랫 아이콘, 스티커, 손그림
- 서버에서 관리하는 스타일 목록은 확장 가능하다.
- 이미지 생성 모델이 이모지 스타일 이미지를 생성한다.
- 생성 결과는 투명 배경 PNG로 출력된다.
- 결과는 캔버스 위 이미지 요소로 배치된다.
- 다른 요소처럼 이동, 크기 조절, 삭제가 가능하다.
- AI 도구 패널의 “이모지 만들기”에서 접근한다.
- 생성 대기 연출은 네모닉 프린터 모션을 재활용한다.
- 실패 시 “이모지를 만들지 못했어요. 다시 시도해 주세요” 안내를 표시한다.
- 캔버스 기존 상태는 영향받지 않는다.
- 사용 횟수 제한은 추후 결정할 수 있다.

### 확장 후보

- Sketch-to-Image
- 스타일 변환
- 배경 제거

## 캔버스 생명주기

- 마지막 접속 사용자가 이탈하는 순간 캔버스가 즉시 삭제된다.
- 시간 기반 TTL이나 만료 정책은 두지 않는다.
- 마지막 사용자가 이탈을 시도하면 경고 모달을 표시한다.
- 예: “나가면 이 캔버스의 모든 작업물이 삭제됩니다. 계속하시겠습니까?”
- 사용자가 확인하면 이탈과 캔버스 삭제가 실행된다.
- 사용자가 취소하면 캔버스에 머문다.
- 활동 중에는 서버에 실시간 자동 저장된다.
- 별도 저장 버튼은 없다.
- 마지막 사용자 이탈로 캔버스가 삭제되면 저장된 Redis 작업물도 제거된다.

## 실시간 협업 구조

- WebSocket 기반으로 드로잉, 요소 배치, 커서 이동 등 모든 작업을 동기화한다.
- 다른 참여자의 커서와 닉네임을 실시간 표시한다.
- 요소 수정 권한은 소유권 구분 없이 누구나 가능하다.
- 한 참여자가 수정 중인 요소는 잠금 표시로 동시 수정을 방지한다.
- 동시 접속 최대 6명, 추후 10명 기준으로 드로잉 데이터 전송 최적화가 필요하다.
- 벡터 압축, 간격 조절 등을 고려한다.

## 네트워크 끊김 대응

무한 캔버스는 서버 실시간 저장을 단일 진실 공급원으로 둔다. 대기방과 라운드 개념이 없으므로 캔버스가
활성 상태인 동안 언제든 재접속 가능하지만, 마지막 참여자 이탈로 종료되면 복귀할 수 없다.

### 재접속 식별

- WebSocket 연결에 `canvasId + UUID`를 매핑한다.
- 캔버스 URL에 `canvasId`가 포함된다.
- UUID는 `localStorage + cookie`에서 복구한다.
- 같은 브라우저이면 동일 UUID를 재전송한다.
- 유예 시간 제한은 없다.
- 캔버스가 활성 상태인 동안 언제든 복귀 가능하다.
- 마지막 참여자가 이탈하면 즉시 종료되어 더 이상 복귀할 수 없다.

### 상황별 처리

| 상황 | 복귀 | 정책 |
| --- | --- | --- |
| 네트워크 순단, 탭 유지 | 가능 | 자동 재연결 후 서버 최신본 동기화 |
| 페이지 새로고침 | 가능 | 동일 URL과 UUID로 서버 저장본 로드 |
| 탭 닫기 후 링크 재진입 | 가능 | 캔버스가 활성 상태인 동안 가능 |
| 브라우저 캐시 삭제 | 조건부 | 새 UUID로 다른 참여자 인식, 내 결과물 조회는 불가 |
| 마지막 참여자 이탈 후 | 불가 | Redis evict로 복구 불가 |

### 끊김 감지와 손실 정책

- WebSocket heartbeat, `navigator.onLine`, ping 주기 체크로 감지한다.
- 끊김 시 “연결 끊김 — 재연결 중...” 오버레이를 표시한다.
- 편집 도구는 잠금 처리한다.
- 짧은 지수 백오프로 재연결을 시도한다.
- 예: 1초, 2초, 4초, 최대 15초 또는 3회
- 성공 시 서버 최신본을 다시 로드한다.
- 실패 시 “새로고침” 버튼을 노출한다.
- 별도 로컬 이벤트 큐 재전송은 하지 않는다.
- 끊기기 직전 서버에 전송되지 못한 몇 초간의 획/요소 변경은 유실될 수 있다.
- 이 손실은 허용 가능한 실행 손실로 간주한다.
- 다른 참여자에게 끊긴 사용자의 커서 옆 “연결 불안정” 표시를 노출한다.
- 일정 시간 이상 복귀하지 않으면 커서를 페이드 아웃한다.

## 사용자 흐름

1. 무한 캔버스 존에 진입한다.
2. 새 캔버스를 생성하거나 공유 링크/QR로 기존 캔버스에 합류한다.
3. 친구 초대가 필요하면 공유 링크 또는 QR을 전달한다.
4. 펜, 스티키노트, 도형, 텍스트, 이미지, 갤러리 결과물 등으로 자유 창작한다.
5. 선택적으로 AI 기능을 활용한다.
6. 출력 모드에서 원하는 영역을 선택한다.
7. 네모닉으로 포스트잇 출력한다.
8. 부착, 소장, 공유한다.

## 주요 기능

- 다양한 캔버스 도구
- 무한 캔버스
- 포스트잇 출력
- AI 기능
- 캔버스 캡처 및 공유
- 자유 합류/퇴장
