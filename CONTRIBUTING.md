# Contributing Guide

This repository keeps detailed contribution rules inside each application area.

## Area Guides

- Backend contribution guide: `backend/CONTRIBUTING.md`
- Frontend contribution guide: `frontend/CONTRIBUTING.md` when the frontend
  area exists

## Merge Requests

Use the relevant template under `.gitlab/merge_request_templates/`.

For backend-only changes, use `.gitlab/merge_request_templates/backend.md`.
