# Repository Agent Guide

This repository is organized by application area. Use this root guide only as
the entrypoint, then follow the guide for the area you are changing.

## Area Guides

- Backend work: read `backend/AGENTS.md`.
- Frontend work: read `frontend/AGENTS.md` when the frontend area exists.

## Common Rules

- Keep changes scoped to the requested area.
- Do not revert user changes unless explicitly requested.
- Run the verification commands documented in the relevant area guide before
  handoff.
- If a change touches multiple areas, state the affected areas and verify each
  one with its own guide.
